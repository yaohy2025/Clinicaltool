临床小工具分享版 · 使用说明
================================

【怎么打开】
  直接双击「index.html」即可使用，完全离线、无需联网、无需安装任何软件、无需起服务器。
  推荐用 Chrome / Edge / 360 / 微信内置浏览器打开。

【文件结构（必须保持原样，不要拆开）】
  临床小工具-v3.28-分享版/
  ├─ index.html          ← 主程序，双击它
  ├─ growth_src.js       ← 生长曲线模块（独立小程序，已内嵌）
  └─ data/          ← 全部数据（11 个 .js 文件）
       ├─ _small.js
       ├─ diseases.js  drugs.js  drugs_peds.js  guidelines.js
       ├─ symptoms.js  labs.js  procedures.js  documents.js
       ├─ drg.js  templates.js
  ⚠️ 这三个东西必须放在同一个文件夹里，删掉或移走任何一个，对应功能都会失效。

【包含哪些功能（共 43 个模块，左侧两级菜单）】
  疾病诊疗：疾病库 / 儿科疾病库 / 症状鉴别 / 儿科症状 / 临床指南
  合理用药：常用药 / 儿科用药 / 泵注药 / 中成药 / 中成药外用 / 皮肤科用药 / 眼科用药 / 急救用药
  用药安全：配伍禁忌 / 皮试 / 高危药品 / 药物过敏 / 妊娠用药 / 基因用药 / 抗菌药分级 / 特殊人群 / 抗生素等级
  检验检查：检验手册 / 危急值 / 临床参考值
  操作文书：操作规范 / 抢救流程 / 文书模板 / 中医方剂
  编码管理：DRG 查询 / ICD-10
  中医：中药 / 针灸穴位
  速查工具：儿童生长曲线 / 疫苗程序 / 医学缩写 / 皮肤病 / 计算器

【体积说明】
  整个文件夹约 54MB，其中 data/templates.js 约 35MB，是「文书模板」模块的数据。
  · 如果接收方不需要「文书模板」，可以删除 templates.js（文件夹会降到约 19MB）；
    删后仅「文书模板」模块点开会提示“数据加载失败”，其余 42 个模块全部正常。
  · 其余模块均为轻量数据，打开秒显。

【隐私与免责】
  · 本工具为内部学习/临床参考用途，数据仅供参考，不能替代临床判断与医嘱。
  · 所有数据均存储在本机，不会上传任何信息。
